# 图像港 Image Port

一个 Manifest V3 Chrome 扩展。通过网页右下角的悬浮按钮，进入「格式批量转换」或「图片批量裁剪」，在本地处理、重命名和下载图片，无需账号或后端服务。

快速上手：[简明使用说明](https://github.com/chandlerler/gpt-image-transfer/blob/main/USAGE.md)。

## 安装

1. [下载插件安装包 ZIP](https://github.com/chandlerler/gpt-image-transfer/raw/refs/heads/main/releases/image-port-chrome.zip) 并解压（开发者也可以按下方命令构建，输出为 `artifacts/image-port-chrome.zip`）。
2. 打开 Chrome 的 `chrome://extensions`，启用右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的目录；本地开发选择 `dist/`。
4. 刷新已打开的普通网页，点击右下角的图片图标。也可以点击浏览器工具栏里的扩展图标。

更新已安装版本：解压新安装包并替换原扩展目录，在 `chrome://extensions` 点击该扩展的「重新加载」，然后刷新使用插件的网页。

需要 Chrome / Chromium 120 或更新版本。Chrome 内部页面、Chrome 应用商店等受保护页面不能插入悬浮按钮，此时工具栏图标会打开独立转换页面。网页刷新会清空该网页面板的内存队列，长批次建议点击悬浮窗标题栏中间的「在新标签页打开 ↗」，把已有工作复制到独立扩展页面。

## 使用

- 面板顶部有「格式批量转换」「图片批量裁剪」两个入口；切换时分别保留队列、设置和处理结果。
- 悬浮面板默认 600 × 600，小屏自动收窄；可拖动顶部标题栏移动面板，右下角的 44 × 44 图标也可独立拖动。拖动不会触发打开或关闭，位置会限制在可见窗口内；收起再打开保留本页的位置与队列。


### 将现有工作复制到网页标签页（1.2.0）

在「格式批量转换」或「图片批量裁剪」中，点击悬浮窗顶部中间的 **在新标签页打开 ↗**。新标签页会同时保留两个工具的原始图片、队列顺序、已填设置、转换结果，以及裁剪位置、逐张命名和格式、勾选状态、ZIP 名称等，并停留在原来选中的工具。处理中点击会等待当前任务完成再复制。

图片通过插件内部消息分块传递，临时保存在本机 IndexedDB 中，不上传网络。成功恢复后删除临时副本；未完成的副本在后续复制操作中按 24 小时有效期清理。存储不足或打开失败时显示错误，原窗口内容不清空。新标签页与原悬浮窗是独立副本，之后的编辑互不覆盖。新页完成恢复后，可关闭原网页继续工作；刷新工作页仍会清空该页内存队列，请先下载结果。

格式转换与裁剪共用同一套浅色／墨绿暗色主题，保留日夜切换开关、极光光晕、暗色粒子与减少动态效果适配。主题选择同步并记忆。44px 圆形双手悬浮球保留，悬停短线按约 2.8 秒周期波动。

### 格式批量转换

- 拖入图片或选择多个文件，可混合不同输入格式，并分次追加文件。
- 选择 PNG、JPG、WebP、GIF、BMP、TIFF 或 ICO 作为统一输出格式。
- JPG / WebP 可设置质量；JPG、BMP、GIF 可指定透明区域的填充颜色。
- 重命名输入框默认填入 `{n}`，起始序号 1、位数 3，直接生成 `001.png`、`002.png` 等名称。可在序号前后添加文字，例如 `旅行_{n}` 生成 `旅行_001.png`；也支持 `{name}`（原文件名），如需保留原名可直接填写 `{name}`。清空模板会回退为 `{n}`；不合法字符会被替换，同名自动加后缀，避免覆盖。
- 可填写最大宽高，保持比例，只缩小不放大。ICO 自动限制到 256 × 256。
- 点击「开始转换」，查看每个文件的成功或失败状态；支持停止后续处理。
- 点击单个文件右侧下载按钮，或「打包下载 ZIP」。失败项不会阻止其他文件转换或下载。
- 转换后可以继续调整名称；修改格式、尺寸、质量或背景色则需要重新转换。

### 图片批量裁剪

整合用户提供的 `image-resizer-crop-theme-v4 (2).html`。原网页作者署名和项目链接保留在裁剪页的「功能说明与原网页来源」中；脚本和样式已拆分为扩展本地资源，兼容 Manifest V3。

| 功能 | 用法 |
| --- | --- |
| 批量导入 | 文件选择、拖入图片或在裁剪页面内按 Ctrl+V 粘贴图片 |
| 输出尺寸 | 800×800、480×480，或自定义宽高（每边 16–4096 像素） |
| 可视化裁剪 | 拖动框内平移、拖动四角缩放；始终锁定输出宽高比，松手自动更新结果 |
| 批量居中 | 「全部居中裁切」重置取景；更改宽高比时也会居中，同宽高比修改尺寸则保留取景 |
| 高清缩放 | 分步降采样；目标大于裁剪区域时允许放大，并显示「已放大」 |
| 按 KB 压缩 | JPEG/WebP 在质量 40%–100% 范围内搜索符合上限的最高画质；留空不限制体积；不能达标时显示「超出上限」 |
| 格式 | JPEG、PNG、WebP；默认格式影响新导入图片，单张格式和统一格式可修改已有图片 |
| 命名 | 单张独立修改；统一命名默认 `{n}`，支持 `{name}`；仅输入普通前缀时沿用原网页的自动追加序号规则 |
| 排序 | 拖动卡片左上角手柄；也可聚焦手柄后按方向键调整；批量命名和导出采用当前顺序 |
| 选择 | 单张勾选、全选/取消全选，只下载选中图片或下载全部成功结果 |
| 导出 | 单张下载、连续下载、ZIP 打包；可自定义压缩包名称，同名自动去重，大批次自动分包 |
| 预览 | 实时显示尺寸、格式、体积、质量与超限提示；点击结果缩略图打开大图预览，支持关闭按钮、遮罩空白、Esc |
| 外观 | 浅色/墨绿暗色切换并记忆；保留按图取色、极光背景、暗色粒子互动及减少动态效果偏好 |

PNG 无画质压缩档位，超限时需改格式或缩小尺寸。JPEG 透明区域填白，PNG/WebP 保留透明。裁剪输入使用浏览器解码能力，不支持 HEIC/RAW 或浏览器不能读取的 TIFF；必要时先在格式转换入口转成 PNG 后导入裁剪。动画按第一帧处理。

## 格式与容量边界

没有任何转换器能保证读取所有格式。本插件读取 Chrome 支持的图片格式（常见 JPG、PNG、WebP、GIF、SVG、AVIF、BMP、ICO），并使用 UTIF.js 补充 TIFF；具体输入仍受文件编码和浏览器能力影响。HEIC / HEIF、相机 RAW、PSD 等不支持的文件会显示失败原因，不会伪装成转换成功。

动画 GIF / WebP 等输出为静态图片；TIFF 仅读取第一页。GIF 输出最多 256 色，并使用指定颜色填充透明区域。SVG 可栅格化导入，不提供矢量导出。PNG、WebP、TIFF 和 ICO 输出保留透明背景，转换不保留 EXIF、GPS 等原始元数据。

队列没有人为的文件数量上限，逐张解码和转换以降低峰值内存。但文件及结果仍保存在内存中，实际容量受设备和浏览器限制；单图上限为 8000 万像素、单边 32767 像素。大批次 ZIP 会在约 512 MB 或 10000 个条目处分包；单个输出超过 2 GB 时请单独下载或缩小尺寸。浏览器可能要求允许多个下载。关闭面板保留当前页面队列，刷新页面或关闭标签页后清空。

## 本地开发

环境：Node.js 20+、npm；浏览器端到端测试使用 Chromium。

```bash
npm ci
npm run build
npm test
npm run test:e2e
# 工作内容跨页面复制与共享主题回归测试
npm run test:workspace
# 在允许加载开发者扩展的 Chromium 环境中运行实际安装测试
npm run test:extension
# 一次运行全部检查
npm run check
```

`npm run build` 生成 `dist/` 和 `artifacts/image-port-chrome.zip`。构建内容包括离线 JS 依赖、图标和第三方许可证，不需要 CDN。端到端测试默认读取 `/usr/bin/chromium`，其他环境使用 `CHROMIUM_PATH=/absolute/path/to/chromium npm run test:e2e`。

默认端到端测试在真实 Chromium 中通过本地测试服务器运行两个工具页，并模拟扩展 runtime API 来测试悬浮窗。覆盖七种格式编码、实际像素/透明度、损坏文件隔离、重命名、ZIP 和单张下载、拖动面板、小屏布局，以及裁剪像素、尺寸/比例、体积压缩、卡片拖动排序、选择下载、粘贴/拖放导入、主题记忆、双入口状态保留。测试截图在 `artifacts/` 下。

`npm run test:extension` 使用同一套用例，以实际已加载扩展的方式运行，不模拟 runtime API。当前云环境设置了 `ExtensionInstallBlocklist: ["*"]` 管理策略，阻止实际安装测试；因此本环境的功能测试不能替代用户 Chrome 上的加载验证。

## 隐私与权限

扩展没有服务器、统计代码或图片上传逻辑；工具页 CSP 禁止网络连接。网页匹配范围用于显示悬浮入口。内容脚本只创建隔离面板，不读取网页文本或图片；只有用户主动选择、拖入或粘贴的图片会被处理。粘贴使用用户触发的 paste 事件，无需剪贴板读取权限。没有请求下载管理、浏览历史等权限，下载通过浏览器的文件下载机制完成。

工作内容复制测试覆盖原网页关闭后的恢复、跨 iframe File/Blob、多分块原图、输出文件逐字节一致、裁剪几何与选择、双向主题同步、处理中复制、失败保留与重试。与原有浏览器测试一样，这些检查使用真实 Chromium 与模拟 Chrome runtime，不能代替用户浏览器中的实际加载验证。

## 代码结构

- `src/content.js`：网页悬浮入口与隔离 iframe。
- `src/background.js`：工具栏点击、独立页面回退和工作内容复制消息。
- `src/workspace-transfer.js`、`src/workspace-store.js`：工作内容与图片的分块复制、本机临时存储及恢复。
- `src/theme.js`、`src/theme.css`、`src/conversion-theme.css`：两个工具共享的主题、日夜开关和背景效果。
- `src/launcher.js`、`src/assets/launcher-hands.png`：圆形双手悬浮入口与悬停波动。
- `src/app.*`：队列、设置、进度、下载与中文界面。
- `src/convert.js`：浏览器解码、Canvas 与各格式编码。
- `src/core.js`：命名、尺寸和二进制文件编码。
- `src/crop.*`、`src/crop-theme.js`：从上传网页整合的裁剪界面、主题、队列和交互。
- `src/crop-core.js`、`src/crop-engine.js`：裁剪几何、命名、分步缩放与体积压缩。
- `src/archive.js`：裁剪结果 ZIP 流式打包和分包。
- `scripts/build.mjs`：离线打包、图标生成和分发 ZIP。

本项目尚未发布到 Chrome 应用商店。
